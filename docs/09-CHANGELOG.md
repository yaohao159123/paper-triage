# CHANGELOG

## 0.4.3 · 2026-09-22

- 修复：X 折叠推文里的引用推文 / X 文章卡片 / 链接卡片仍完整显示（用户截图）。折叠推文内所有 `div[role="link"]`、文章封面、媒体、操作栏一律隐藏，并给折叠推文加 64px 高度上限兜底。

## 0.4.2 · 2026-09-22

- 修复：X 上「跳过」的推文既不折叠也不变灰（用户截图确认）。根因：X 由 React 渲染，推文与格子的 `class` 由 React 管理，重绘时会覆盖掉扩展加的 `pt-skipped` 等类，只剩徽章。现在容器与页面级状态全部改用 `data-pt-*` 属性（React 不会改写），CSS 全部改为属性选择器。
- 修复：旧版本缓存的推文判定没有套用「推广直接跳过」规则（截图里的大学广告显示「普通」）。缓存命名空间加入策略版本号，旧判定自动失效并重判。

## 0.4.1 · 2026-09-22

- 修复：X 时间线「隐藏」不生效。X 是虚拟列表，每条推文外层是绝对定位的 `cellInnerDiv`，之前只隐藏内层 `article`，格子仍占位；现在容器为 [article, cell]，隐藏 / 只看关注 作用到整个格子。
- 修复：虚拟列表滚动时重新挂载的推文 / 卡片会先以原样闪现再变灰。重新挂载时立即套用本地已有判定（不再等防抖与后台往返），防抖从 600 ms 缩到 150 ms；已判定过的条目不再重复请求。

## 0.4.0 · 2026-09-22

- 新增小红书网页版（探索页 / 搜索页 / 笔记弹层）：只看学习内容，独立小红书画像；屏蔽项默认隐藏并自动重排瀑布流；学习类卡片描绿框。
- 推文与小红书：推广 / 广告概率 ≥ 0.8 直接判跳过（阈值可调）。
- Twitter 折叠重做：跳过推文折成一行（隐藏媒体 / 引用 / 操作栏，正文单行截断，头像缩小）。
- 每个站点可单独选择跳过项的显示方式（工具条下拉），选择记住。
- 设置页新增小红书画像与 promoSkipMin。

## 0.3.0 · 2026-09-22

- 跳过项默认折叠成一行，连续跳过合并为「已折叠 N 条」（点击展开），单条双击展开；可切换为「变灰」或「隐藏」，偏好持久化。
- 关注项加左侧绿色色条与淡底色（可关闭）。
- 徽章旁显示命中维度（文献：课题 / 方法 / 材料；推文：主题 / 具体 / 来源），tooltip 给概率；可关闭。
- 模型把握不大的徽章改为虚线边框。
- 工具条新增「关注置顶」（Alt+S），按关注 → 普通 → 跳过 重排并可恢复；工具条重新组织为下拉 + 开关。
- 设置页新增「显示方式」一节。

## 0.2.0 · 2026-09-22

- 新增页面工具条：计数、只看关注 / 隐藏跳过、跳到下一条关注、重判；快捷键 Alt+N / Alt+F / Alt+H。
- 新增多套文献画像（新建 / 重命名 / 删除 / 弹窗切换）；缓存按画像哈希分命名空间，改画像自动重判。

- 新增弹窗「复制本页『关注』为 Markdown」。

## 0.1.0 · 2026-09-22

- 首版：Chrome MV3 扩展，在 Google Scholar / arXiv（列表页 + 搜索页）/ PubMed 列表页为每条文献注入 关注 / 普通 / 跳过 徽章，跳过项整条灰化、悬停恢复。
- 判断：TypeSafe Jev，每篇一个三级 Score（读的优先级）+ 一个 Noul（是否综述），每批 10 篇一次请求、批次并行；阈值策略在代码里（followMin 0.5 / skipMin 0.6）。
- 本地缓存（DOI / arXiv ID / 规范化标题为键）；点击徽章手动改判并持久化，⌥+点击恢复 AI；弹窗可开关、本页重判；选项页配置 Key / 模型 / 研究画像 / 阈值 / 批大小，可测试连接、清缓存。
- 测试：22 个单元测试、Jev 实测脚本、无头 Chromium 端到端脚本。
