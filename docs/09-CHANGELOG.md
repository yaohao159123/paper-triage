# CHANGELOG

## 0.4.6 · 2026-09-22

- 修复：四个快捷键（Alt+F 只看关注、Alt+N 下一条关注、Alt+S 关注置顶、Alt+H 隐藏 / 折叠）在 macOS 上从未生效。Option+F 送来的键值是「ƒ」而不是「f」（Option+N / H 是死键），原来按 `e.key` 比对必然落空；现在按物理键位 `e.code` 判断。这是 Scholar 上「只看关注时灵时不灵」的直接原因之一（按钮能用、快捷键不能用）。
- 「只看关注」开启时页面右上角常驻提示条：显示 N 条关注 · 隐藏 M 条 · 判读中 / 未判读几条，本页无关注项时明说，带「显示全部」退出。之前筛选状态跨翻页、换搜索词一直保留但页面上没有任何提示，翻到全是关注或全无关注的页面时看起来像「没反应」或「结果莫名变少」。
- 未判读（出错）的条目在只看关注下不再被隐藏（之前失败对用户不可见、也无法点徽章重试）；工具条把「未判读」与「判读中」分开计数。
- 真实 Scholar 核对（专用 Chrome、登录态）：DOM 结构与适配器一致，Scholar 自身 JS 在悬停 / 滚动后零次改动 DOM，扩展 CSS 注入后折叠 / 隐藏 / 只看关注均按预期生效并可恢复；隐藏机制本身在 Scholar 上没有问题。

## 0.4.5 · 2026-09-22

- 修复：小红书「只看关注」/「隐藏」时灵时不灵。①站点在滚动加载、图片加载、窗口缩放后会重算瀑布流位置并覆盖扩展写的位置，且不新增节点，扩展察觉不到；现在监听卡片 style 改动，识别到是站点改的就 120 ms 内重排一次（自己写的忽略，不会死循环），窗口缩放同样重排。②位置只认行内 transform / left-top；现在样式表给的（computed）位置也能读，重排不再静默失败。③「只看关注」会把打开的笔记弹层标题一起藏掉；单条页 / 弹层条目现在带 `data-pt-single`，任何筛选都不隐藏它。
- 信息流站点的「只看关注」更严格：小红书没标题 / 未判定的卡片、X 上非推文的格子（推荐关注、广告模块）也一并隐藏，只留关注。
- 瀑布流站点不再插入「已折叠 N 条」标记（没有连续的概念，且会干扰站点的列表 diff）。
- 弹窗新增「复制诊断信息」：把当前页在扩展眼里的状态（站点、模式、计数、未标记数、瀑布流容器与前 4 张卡片的位置样式）复制成 JSON，方便排查登录态下的问题。

## 0.4.3 · 2026-09-22

- 修复：X 折叠推文里的引用推文 / X 文章卡片 / 链接卡片仍完整显示（用户截图）。折叠推文内所有 `div[role="link"]`、文章封面、媒体、操作栏一律隐藏，并给折叠推文加 64px 高度上限兜底。

## 0.4.2 · 2026-09-22

- 修复：X 上「跳过」的推文既不折叠也不变灰（用户截图确认）。根因：X 由 React 渲染，推文与格子的 `class` 由 React 管理，重绘时会覆盖掉扩展加的 `pt-skipped` 等类，只剩徽章。现在容器与页面级状态全部改用 `data-pt-*` 属性（React 不会改写），CSS 全部改为属性选择器。
- 修复：旧版本缓存的推文判定没有套用「推广直接跳过」规则（截图里的大学广告显示「普通」）。缓存命名空间加入策略版本号，旧判定自动失效并重判。

## 0.4.1 · 2026-09-22

- 修复：X 时间线「隐藏」不生效。X 是虚拟列表，每条推文外层是绝对定位的 `cellInnerDiv`，之前只隐藏内层 `article`，格子仍占位；现在容器为 [article, cell]，隐藏 / 只看关注 作用到整个格子。
- 修复：虚拟列表滚动时重新挂载的推文 / 卡片会先以原样闪现再变灰。重新挂载时立即套用本地已有判定（不再等防抖与后台往返），防抖从 600 ms 缩到 150 ms；已判定过的条目不再重复请求。
